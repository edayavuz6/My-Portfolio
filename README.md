This project is the personal portfolio website of Eda Yavuz, a Frontend and Email Template Developer. It is designed with a creative and friendly approach, emphasizing a continuous growth mindset and modern web standards.

Key Features:

Tech Stack: Built with React and Tailwind CSS.

Email Templates: Visually appealing, custom-designed templates using MJML and HTML.

Responsive Design: Fully compatible with mobile and desktop devices.

Performance: Fast and optimized loading times using Vite.

🛠 Tech Stack / Teknoloji Yığını
Frontend: React, Tailwind CSS

Tooling: Vite, ESLint

Deployment: Vercel

Email Design: MJML, HTML/CSS
